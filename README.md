# Ratatoskrr

Open-source HTTP API and dashboard for WhatsApp accounts, built on
[whatsmeow](https://github.com/tulir/whatsmeow).

**Under development.** The first public release (Alpha) will land here.

> Unofficial client: WhatsApp may restrict or ban numbers that look automated.
